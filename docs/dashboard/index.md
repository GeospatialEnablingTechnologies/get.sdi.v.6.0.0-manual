# Dashboards

A dashboard is a page that shows statistics and raw data, transormed and visualised into charts, tables and maps.

## Dashboard Types

When you open a dashboard, you'll land on one of two page types:

* **A page full of charts**: this is a **Standard Dashboard**. The whole screen is a grid of charts and tables. Good for getting an overview at a glance.
* **A big map with a panel of charts beside it**: this is a **Map Dashboard**. Here the charts and the map work together: you draw a shape on the map, and the charts recalculate for just that area. Good for asking "what's going on here?"

It is organized into the following areas:

* **[Chart Types](chart-types.md)** - the six kinds of charts a dashboard can show, and how to interact with each.
* **[Standard Dashboard](standard-dashboard.md)** - a grid of coordinated charts and tables giving an overview at a glance.
* **[Map Dashboard](map-dashboard.md)** - a map and chart panel wired together, so drawing an area recalculates every chart.
