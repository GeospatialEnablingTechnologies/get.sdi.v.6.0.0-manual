# Map

The **Map Viewer** can be accessed by clicking any publicly available map on the home page. As a core application feature, it provides essential tools for interacting with and managing spatial data.

It is organized into the following areas:

* **[Sidebar](sidebar.md)** - collapsible panel providing layer management, search, styling, and other map tools.
* **[Toolbar](toolbar.md)** - quick-access map interaction tools.
* **[Attribute Table](attribute-table.md)** - tabular view of feature data across the viewer.
* **[Right Click](right-click.md)** - contextual menu for map events and actions.
* **[Export and Import](export-import.md)** - save and restore a map session configuration.
